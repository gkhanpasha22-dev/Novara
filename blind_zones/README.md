# @blind_zones — рабочая среда

Инструментарий для генерации карточек и Reels-видео образовательного аккаунта
**@blind_zones** («Слепые зоны»). Полный контекст проекта, регламент, голос,
границы и список 30 тем — в **[MASTER.md](./MASTER.md)**. Этот README — только про то,
как физически работать со средой.

> **Важно (из MASTER.md):** любой факт публикуется только после проверки источников
> по регламенту (раздел 3 мастер-документа). Инструменты ниже — про оформление,
> а не про содержание. Проверку темы это не заменяет.

## Структура

```
blind_zones/
├── MASTER.md            # источник правды по всему проекту
├── bootstrap.sh         # восстановление среды после сброса контейнера
├── new_topic.py         # создать папку новой темы (build.py + report.md)
├── base/
│   ├── make.py          # модуль генерации карточек (пути к шрифтам — относительные)
│   ├── render.sh        # сборка reel.mp4 из s1..s4.png (14 c, без звука)
│   └── fonts/           # Montserrat Bold / Medium (в git, чтобы пережить сброс среды)
└── topics/<slug>/       # рабочая папка одной темы: build.py, report.md, png, mp4
```

## Разовая настройка новой сессии

Системные пакеты (Pillow, ffmpeg) не переживают полный сброс контейнера — восстановить:

```bash
bash blind_zones/bootstrap.sh
```

Скрипт ставит Pillow и ffmpeg, проверяет наличие шрифтов и прогоняет самотест пайплайна.
Шрифты и `make.py` лежат в git, поэтому заново их создавать/качать не нужно.

## Как сделать один пост

```bash
cd blind_zones

# 1. Создать папку темы (slug — латиницей, коротко)
python3 new_topic.py izvineniya

# 2. Проверить источники по регламенту (раздел 3 MASTER.md) и заполнить:
#    topics/izvineniya/build.py   — тексты 5 карточек (cover + s1..s4)
#    topics/izvineniya/report.md  — доклад владельцу (7 разделов)

# 3. Сгенерировать карточки
cd topics/izvineniya && python3 build.py

# 4. Собрать видео
bash ../../base/render.sh .
```

На выходе: `cover.png` (обложка), `s1..s4.png` (слайды), `reel.mp4` (видео).
Плюс подпись + 10 хэштегов текстом (шаблон — раздел 5 MASTER.md) и доклад `report.md`.

## Визуальные параметры (зафиксированы, см. раздел 6 MASTER.md)

1080×1920 · фон `#0a0a0a` · текст белый · линия `#c0392b` 340×5px ·
бренд-метка «СЛЕПЫЕ ЗОНЫ» серым сверху · Montserrat Bold/Medium · **без нумерации слайдов**.

## Что среда НЕ делает автоматически

- **Не проверяет факты** — проверка источников и вердикт по теме за человеком/ассистентом,
  веб-поиск обязателен для каждой темы.
- **Не публикует** — публикация вручную/через Meta Business Suite, 19:00 МСК (раздел 8).
- **Не решает мировоззренческие темы** — темы из раздела 4 требуют явного одобрения владельца.
