# Статистика опубликованных постов @blind_zones

Журнал разборов статистики по каждому посту — чтобы данные не терялись между
сессиями (среда не персистентна, см. MASTER.md разделы 6/10). Заполняется по
скриншотам от владельца (раздел 8 MASTER.md: Обзор / Вовлечённость / Аудитория).

Ориентиры из MASTER.md: типичный потолок ~120–130 просмотров; два прорывных
поста дали 325 и 445 — оба на темы с конкретным фактом + внешним авторитетом;
типичный skip rate 25–52%; прямое обращение «Ты...» в хуке снижает пропуски
сильнее, чем хуки-констатации/цитаты (наблюдение, не железный закон).

## Тема №29 — «Одна жертва трогает больше, чем тысяча» (эффект узнаваемой жертвы)

**Дата разбора:** 2026-07-25 (пост уже был опубликован, дата публикации неизвестна)

**Обзор:**
- Просмотры: 115 · Охваченные аккаунты: 100
- Среднее время просмотра: 3 с. из 14 (< длительности слайда 1 — 3.5 с.)
- Лайки: 0 · Комментарии: 1 · Репосты: 0 · Поделились: 0 · Сохранения: 0
- Подписки с ролика: 0 · Посещения профиля: 0

**Доля пропусков (skip rate): 59,2%** — маркирован Instagram как «Выше»
(типичный диапазон по истории аккаунта — 25–52%).

**Источники просмотров:** Вкладка Reels 78,9% · Интересное 20,2% · Лента 0,9%

**Аудитория:** 100% неподписчики. Возраст: 18–24 — 24,6%, 25–34 — 44,7%,
35–44 — 23,7%, 45–54 — 6,1%, 65+ — 0,9%. Совпадает с установленным ядром
аккаунта.

**Вывод:** охват — в пределах типичного потолка, не прорыв и не провал.
Ключевая проблема — удержание на первой карточке: среднее время просмотра
(3 с.) меньше длительности самого слайда 1 (3.5 с.), то есть большинство
зрителей уходит, не дойдя до слайда 2. Skip rate выше обычного диапазона.
Вовлечённость (лайки/сохранения/репосты) — нулевая по всем каналам, кроме
комментариев (1,0%, «Выше» — тема зацепила тех, кто досмотрел).

**Гипотеза:** хук поста — констатация («Одна жертва трогает больше, чем
тысяча»), а не прямое обращение к зрителю на «ты». Согласуется с уже
задокументированным в MASTER.md наблюдением, что хуки на «Ты...» дают
меньший skip rate, чем хуки-констатации. Второе наблюдение в пользу этого
правила (было 1, стало по сути 2 — эмпирическое правило раздела 2 строится
на таком же малом числе наблюдений, стоит продолжать копить).

**Что взять в следующие посты:** держать хук в форме прямого обращения
(как уже сделано в теме №15 «10 000 часов» — «Хочешь стать экспертом?»).
