# Конвейер: клиентский сайт из этого репозитория за 6–10 часов

Цель — чтобы каждый новый проект был **конфигом, а не переписыванием**. Пока вы правите
компоненты руками под каждого клиента, себестоимость проекта остаётся высокой, и спекулятивные
демо перестают быть выгодными.

## Шаг 0. Один раз: сделать шаблон конфигурируемым

Сейчас тексты зашиты в компонентах (`src/components/Services.astro` и др.). Задача — вынести всё,
что меняется от клиента к клиенту, в один файл.

Промпт для Claude Code (выполнить один раз в этом репо):

> Вынеси весь клиентский контент из компонентов в `src/config/site.ts`: название компании, слоган,
> контакты, соцсети, услуги, кейсы, этапы процесса, цифры, команда, отзывы, FAQ, SEO-поля
> (title/description/OG), палитра (accent-цвета) и список включённых секций.
> Компоненты должны импортировать данные оттуда, вёрстку не менять. Секции должны отключаться флагом
> в конфиге, а порядок задаваться массивом в `src/pages/index.astro`. Проверь `npm run build`.

Дальше новый клиент = новая ветка + новый `site.ts` + свои цвета. Это и есть «6 часов вместо 3 дней».

Полезно завести `configs/` с готовыми нишевыми пресетами: `dental.ts`, `detailing.ts`, `lawyer.ts`.

## Шаг 1. Бриф (30 минут, до начала работы)

Минимум, без которого не начинать:
- Название, сфера, город, телефон, почта, мессенджер для заявок
- 3–6 услуг с ценами (или «от X ₽»)
- Чем отличаются от конкурентов — 3 пункта
- 2–3 примера работ / кейсов, фото
- Логотип (или его отсутствие — тогда делаем текстовый)
- Ссылки на 2 нравящихся сайта
- Домен: есть/нет, у какого регистратора

Дайте бриф в виде списка вопросов в мессенджере — так заполняют чаще, чем гугл-форму.

## Шаг 2. Сборка (3–5 часов)

1. `git checkout -b client/<название>` — каждый клиент в своей ветке.
2. Заполнить `src/config/site.ts` данными из брифа.
3. Палитра: поменять акцентные токены в `src/styles/global.css` (custom properties). Проверить обе темы
   — светлую и тёмную.
4. SEO в `src/layouts/Layout.astro` подтягивается из конфига; проверить `keywords`, `author`,
   JSON-LD `Organization` (адрес, телефон, соцсети клиента).
5. `astro.config.mjs` → `site: 'https://<домен клиента>'`. **Не забыть** — от этого зависят canonical
   и sitemap. Заодно `Sitemap:` в `public/robots.txt`.
6. Форма: `.env` → `PUBLIC_FORM_ENDPOINT` (Formspree/Web3Forms/Getform). Без него форма в демо-режиме —
   для демо это нормально, для сдачи **нет**.
7. OG-картинка: заменить `public/assets/og-image.svg` на PNG 1200×630 (часть соцсетей не читает SVG).
8. Favicon и `site.webmanifest` — под бренд клиента.
9. Блог (пакет ПРО): 2–3 стартовые статьи в `src/content/blog/`, проверить `/admin` (Decap CMS,
   инструкция в `DEPLOY.md`).

## Шаг 3. Проверка перед показом (30 минут)

- [ ] `npm run build` без ошибок, `npm run preview` открывается
- [ ] Мобильный вид: 360px, 390px, 768px — нет горизонтального скролла
- [ ] Светлая и тёмная тема, переключатель, нет мигания при загрузке
- [ ] PageSpeed Insights (мобильный) ≥ 90 — это то, что вы обещали в договоре
- [ ] Форма реально доставляет заявку (отправить тестовую, показать клиенту скриншот)
- [ ] Все телефоны/почты кликабельны, ссылки на соцсети открываются
- [ ] Нет текста-рыбы, нет «Lorem», нет упоминаний NOVARA в клиентском сайте
- [ ] `sitemap-index.xml` и `robots.txt` отдаются, canonical указывает на боевой домен
- [ ] Проверить орфографию всех текстов

Отдельный промпт для Claude Code перед сдачей:

> Проверь проект перед сдачей клиенту: остались ли где-то плейсхолдеры, демо-тексты, ссылки на
> novarabuild.netlify.app, несоответствия `site` в astro.config и robots.txt, отсутствующие alt у
> картинок, битые якоря в навигации. Собери отчёт списком.

## Шаг 4. Сдача (1 час)

1. Деплой на Netlify (`netlify.toml` уже настроен), подключить домен клиента.
2. Домен и хостинг — **на аккаунт клиента**. Вас добавляют как участника.
3. Яндекс.Метрика + цель на отправку формы, доступ клиенту.
4. Отправить в Яндекс.Вебмастер и Google Search Console, загрузить sitemap.
5. Записать видео на 3–5 минут: как менять тексты через `/admin`, куда приходят заявки.
6. Получить остаток оплаты → передать доступы и репозиторий.
7. **Сразу попросить отзыв** — в день сдачи, пока клиент доволен. Через неделю уже не ответят.
8. Предложить сопровождение: «первый месяц бесплатно, дальше 8 000 ₽/мес».

## Шаг 5. Через 2 недели

Написать клиенту: сколько заявок пришло, что можно улучшить. Это разговор, из которого рождается
допродажа (вторая посадочная, блог, бот) и рекомендация знакомым — самый дешёвый источник клиентов.

---

## Что нельзя делегировать Claude Code

- Разговор с клиентом и выяснение, что у него на самом деле болит.
- Финальную вычитку текстов, которые увидит его аудитория.
- Проверку, что форма доходит: тестируйте руками, всегда.
- Обещания в договоре — отвечаете за них вы.
