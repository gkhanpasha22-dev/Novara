# Приёмная — прототип

Единый инбокс заявок для микробизнеса: Telegram, форма сайта и Авито в одном экране.
Прототип для показа предпринимателям — обоснование продукта в
[`docs/money/DAILY-TOOL.md`](../../docs/money/DAILY-TOOL.md).

**Ноль внешних зависимостей.** Node 22+ со встроенным SQLite, панель на обычных HTML/CSS/JS.
`npm install` не нужен — запускается на любом ноутбуке, в том числе без интернета.

## Запуск за 30 секунд (демо, без бота)

```bash
cd apps/priemnaya
npm run demo
# открыть http://localhost:8787
```

Загрузятся демо-диалоги — панель можно показывать клиенту сразу, без бота и без интернета.
`npm run reset` очищает базу, чтобы показать всё с чистого листа.

## Боевой запуск с Telegram

1. Создать бота у [@BotFather](https://t.me/BotFather) → получить токен.
2. `cp .env.example .env` и заполнить `BOT_TOKEN`.
3. `npm start`.
4. Написать боту любое сообщение — диалог появится в панели, ответ из панели уйдёт в Telegram.
5. Узнать свой `OWNER_CHAT_ID` (для сводки дня): открыть `http://localhost:8787/api/whoami`
   и взять `external_id` своего чата. Вписать в `.env`, перезапустить.

Используется long polling — публичный домен и вебхуки не нужны, работает с ноутбука.

## Заявки с сайта

Форма лендинга NOVARA уже умеет слать `POST` на произвольный эндпоинт. Достаточно указать в
`.env` основного проекта:

```
PUBLIC_FORM_ENDPOINT=http://localhost:8787/api/intake
```

Принимаются `multipart/form-data`, `application/json` и `x-www-form-urlencoded`.
Поля: `name`, `phone`, `email`, `message`, `source` (`site` по умолчанию), `company` — honeypot.
Заявка появляется в панели, а владельцу уходит уведомление в Telegram.

Тот же эндпоинт годится для любого источника, который умеет слать HTTP:

```bash
curl -H 'content-type: application/json' \
  -d '{"name":"Ахмед","phone":"+79280001234","text":"Нужен дом на 5 ночей","source":"avito"}' \
  http://localhost:8787/api/intake
```

## Что умеет

- Все обращения в одном списке с фильтрами «Новые / В работе / Готово» и поиском.
- Переписка и ответ прямо из панели (Ctrl+Enter — отправить).
- Шаблоны быстрых ответов — вставляются одним нажатием.
- Карточка клиента: имя, телефон, статус, заметка. Сохраняется автоматически.
- Напоминания «через час / завтра / через 3 дня» → приходят владельцу в Telegram.
- Автоответ на первое сообщение нового клиента (`AUTOREPLY` в `.env`, срабатывает один раз).
- Сводка дня в Telegram в заданный час (`DIGEST_HOUR`) и по кнопке в панели.
- Живое обновление панели через SSE — новые сообщения появляются без перезагрузки.
- Светлая и тёмная тема, работает с телефона.

## Ограничения прототипа (осознанные)

- Ответить можно только в Telegram. Заявки с сайта и Авито — только чтение: в карточке есть
  телефон, звоните. Обратный канал Авито требует их API и отдельного договора.
- Один пользователь, без ролей и разделения прав. `PANEL_PASSWORD` — простой замок от
  случайного захода, не защита от целенаправленного взлома. В интернет без HTTPS не выставлять.
- Нет MAX: там ботов публикуют только верифицированные юрлица РФ. Telegram-контур строится
  первым специально — его можно показывать уже сегодня, пока идёт регистрация ООО.
- `node:sqlite` помечен в Node как экспериментальный API. Для прототипа это приемлемо;
  при переходе в продакшен — на PostgreSQL, схема совместима.

## Структура

```
apps/priemnaya/
├── src/
│   ├── config.js    # чтение .env без зависимостей
│   ├── db.js        # схема SQLite и запросы
│   ├── telegram.js  # long polling + отправка сообщений
│   ├── digest.js    # сводка дня и напоминания
│   ├── seed.js      # демо-диалоги для показа
│   ├── reset.js     # очистка базы
│   └── server.js    # HTTP: панель, API, SSE
└── public/          # панель: index.html, styles.css, app.js
```

## Что показывать предпринимателю

Открыть панель на ноутбуке и задать один вопрос: **«Как вы сейчас принимаете заказы после
блокировки WhatsApp?»** Дальше не рассказывать про функции, а показать, как выглядит его
собственный день, если все заявки лежат в одном месте. Решение принимается за минуту.
